🚀 Personal Portfolio

A personal portfolio showcasing interactive animations and illustrations built with React, Rive, Framer Motion, and Lottie.

✨Technologies

React 
Tailwind CSS
Framer Motion
Rive / Lottie 


📍The Process

I wanted a dedicated spot to show off all my creative work as I am passionate about building cool designs, animations, and interactions on the web. Most standard portfolios felt too static, so I set out to build something that felt alive and interactive. I structured the portfolio so that each card takes you to a completely different project, letting me showcase various technologies I used. The best part? It's fully responsive, so the experience looks great and works smoothly on mobile too! 

🚦Running the Project

1. Clone the repository
2. Install dependencies: npm install
3. Run development server: npm run dev
4. Open http://localhost:5173 in your browser
